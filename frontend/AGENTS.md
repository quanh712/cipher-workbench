## Monorepo frontend

This is the active frontend. Read `../AGENTS.md` and use the monorepo root for
local/public deployment. `deploy/` recipes copied into this frontend are legacy
recovery tools; normal local Docker uses `../compose.yaml`. Do not edit the
sibling legacy repository `../../cipher-workbench-fe` for new features.
